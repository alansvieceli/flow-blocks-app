# UI Design — Flow Blocks

Data: 2026-06-16

## Visão geral

Design aprovado para a v1 do Flow Blocks. Cobre navegação, identidade visual e estrutura de todas as telas.

---

## Navegação

Tab bar fixa na parte inferior com 4 abas:

| Aba       | Ícone (Lucide/Feather outline) | Conteúdo                                                                 |
| --------- | ------------------------------ | ------------------------------------------------------------------------ |
| Início    | `home`                         | Tela principal: métricas do dia + início rápido + plano pessoal da noite |
| Painel    | `grid` (2x2)                   | Dashboard: gráficos por equipe/categoria, heatmap, totais                |
| Lembretes | `bell`                         | Lista de lembretes agendados                                             |
| Mais      | `more-horizontal` (3 pontos)   | Menu de configurações                                                    |

---

## Identidade visual

### Paleta

- **Fundo principal**: `#0f0f1a`
- **Fundo cards/superfícies**: `linear-gradient(135deg, #1a1a2e, #16213e)`
- **Borda de cards**: `#2a2a4a`
- **Cor de destaque (primária)**: gradiente `#7c3aed → #3b82f6` (roxo → azul)
- **Cor de ação destrutiva / parar**: gradiente `#dc2626 → #f97316` (vermelho → laranja)
- **Cor de alerta**: `#f97316` (laranja)
- **Cor de sucesso / pessoal**: `#16a34a` (verde)
- **Texto principal**: `#ffffff`
- **Texto secundário**: `#5a5a8a`
- **Texto desabilitado/inativo**: `#2a2a4a`

### Tipografia

- Fonte do sistema: `-apple-system` / `SF Pro Display` (React Native padrão)
- Títulos de tela: `font-size: 18px, font-weight: 800, letter-spacing: -0.5px`
- Subtítulos/rótulos: `font-size: 9px, text-transform: uppercase, letter-spacing: 1px, color: #3a3a6a`
- Corpo: `font-size: 12px, color: #ccc`
- Números de destaque (métricas): `font-size: 16-44px, font-weight: 800, cor primária`

### Componentes recorrentes

- **Cards**: `border-radius: 18px`, fundo gradiente, borda `#2a2a4a`
- **Chips de seleção ativo**: fundo gradiente primário, texto branco, `font-weight: 700`
- **Chips de seleção inativo**: fundo `#12122a`, texto `#3a3a6a`, borda `#2a2a4a`
- **Botão principal (iniciar)**: gradiente primário, `border-radius: 12px`, `font-weight: 800`, sombra roxa
- **Botão parar sessão**: gradiente destrutivo, mesma geometria
- **Ícones da tab bar**: estilo outline/line (Lucide), `22x22px`, `stroke-width: 1.8`, ativo em `#7c3aed`, inativo em `#2a2a4a`
- **Pill de streak**: gradiente laranja `#ff6b35 → #f7931e`, texto branco, `font-weight: 800`

## Telas

### 1. Home (Início)

Estrutura de cima para baixo:

1. **Cabeçalho**: data + saudação ("Bom dia, Alan 👋") + pill de sequência (streak)
2. **Métricas do dia**: 3 cards lado a lado — Total hoje / Equipe X / Equipe Y
3. **Card "Novo bloco"**: chips de categoria (Foco Profundo, Reuniões, Revisão, Admin) + chips de equipe + botão Iniciar
4. **Card "Esta noite"**: preview do plano pessoal do dia (atividades com duração planejada, fundo verde escuro)

### 2. Sessão ativa

Aparece quando há uma sessão em andamento (substitui o card "Novo bloco"):

1. **Indicador "Gravando"**: ponto laranja pulsante + label
2. **Cronômetro crescente**: fonte 44px, peso 900, destaque total
3. **Chips**: categoria e equipe selecionadas (não editáveis durante sessão)
4. **Hora de início**: "Iniciado às HH:MM" em cor discreta
5. **Botão Parar**: gradiente destrutivo
6. **Campo de nota rápida** (opcional): card abaixo do botão
7. **Resumo do dia**: total + por equipe, linha discreta abaixo

Status bar mostra o cronômetro rodando enquanto o usuário navega para outras abas.

### 3. Histórico

Acessado via aba Mais → Histórico:

1. **Filtro**: chips Hoje / Semana / Mês
2. **Lista agrupada por dia**: cabeçalho do grupo com data e total do dia
3. **Item de sessão**: ícone da categoria + nome categoria + equipe + hora início → fim + duração
4. Toque no item abre detalhe com nota (se houver)

### 4. Painel

1. **Seletor de período**: Semana / Mês (canto superior direito)
2. **Por equipe**: barras horizontais com % e horas; alerta laranja (⚠️) quando acima da meta
3. **Por categoria**: barras horizontais com cores em tons do gradiente primário
4. **Heatmap**: grid de concentração por hora do dia (7 linhas × 8 colunas representando faixas horárias), intensidade em tons de roxo
5. **Cards de totais**: Total semana / Sequência / Trocas de contexto

### 5. Lembretes

1. **Botão "+ Novo"** no header
2. **Seção "Próximos"**: lista com ícone bell + título + data/hora + equipe/categoria vinculada (se houver)
3. **Seção "Passados"**: mesma lista com opacidade reduzida (35%)
4. Toque abre edição; swipe para deletar

### 6. Plano pessoal do dia

Acessado via card "Esta noite" na Home ou aba Mais → (via seção Pessoal):

1. **Header**: "🌙 Esta noite" + data + badge "Pré-preenchido do template"
2. **Lista de atividades**: checkbox + nome da atividade + duração planejada
   - ✓ feito: fundo verde escuro, texto verde claro
   - ✕ não rolou: texto riscado, opacidade reduzida
   - vazio: pendente
3. **Resumo**: card no final com contagem (X feito · X não rolou · X pendentes)
4. **Botão "+ Adicionar"** no header para adicionar atividade avulsa ao dia

### 7. Mais (menu)

Lista de itens com separação em seções:

- **Trabalho**: Equipes, Histórico
- **Pessoal**: Atividades, Template semanal
- **App**: Lembretes

### 8. Equipes

1. **Botão "+ Adicionar"** no header
2. **Lista de equipes**: cor da equipe (dot colorido) + nome + meta de % (se configurada) + % atual da semana
3. Alerta laranja quando % atual > meta
4. Toque abre edição (nome + cor + meta de %)
5. **Botão "Nova equipe"** no final da lista

### 9. Template semanal

1. **Lista dos 7 dias** (Seg → Dom)
2. Cada linha: dot roxo (com template) ou cinza (sem) + nome do dia + preview das atividades + link "Editar" ou "Adicionar"
3. Toque abre edição do dia: lista de blocos (atividade + duração) com botão para adicionar mais

## Decisões de UX

- **Sessão órfã**: se o app for fechado com sessão ativa, ao reabrir detecta o `startedAt` salvo e pergunta ao usuário se deseja encerrar a sessão.
- **Interrupção de bloco**: fluxo recomendado é parar a sessão atual e iniciar uma nova com a categoria correta (sem edição retroativa de sessões).
- **Reinício rápido**: após parar uma sessão, botão de reinício com a mesma equipe + categoria fica disponível na Home.
- **Sem timer background**: o cronômetro é calculado de `agora - startedAt` a cada segundo, apenas com a tela visível. Sem impacto de bateria.
- **Notificações**: apenas para lembretes agendados, via `expo-notifications` gerenciado pelo OS.
